ZCode 官方插件的跨 agent 移植层 —— 不是再汉化一遍，是让别的 agent 也能用

本页是 zai-org/zcode-plugins（ZCode 官方插件仓库，Apache-2.0）的移植镜像：{{TOTAL}} 个插件源码逐字节保留，由 tools/verify.mjs 在每次发布前逐文件对账。ZCode 插件自带中文元数据，所以这里不翻译，缺的是别的 agent 认不认——这就是每个卡片上那档判定：✅ 直接可用 / ⚠️ 部分可用 / ❌ 装了也没用。

一键市场只收录「直接可用」的 {{CLEAN}} 个：装进 Claude Code / Codex 后技能、命令、代理、MCP 与 ZCode 下一致。其余插件不在一键市场——它们各有明确缺口（ZCode 专有 hooks、宿主托管 MCP、上游没提交的构建产物），但源码仍然逐字保留在本仓库里作为原始资料，矩阵逐条写明缺在哪，改造即可用。

安装（Claude Code）：claude plugin marketplace add kael-odin/zcode-plugins-zh；安装（Codex）：codex plugin marketplace add https://github.com/kael-odin/zcode-plugins-zh.git 然后 codex plugin add zcode-github@zcode-plugins-zh，装完重开会话。契约依据见仓库内 docs/codex-contract.md。
